# Архитектура интерфейса: ПК и мобильная версия

Канон: **React** в `apps/web`. Breakpoint: **desktop ≥ 768px**, **mobile < 768px** (`useIsDesktop`).

Связано: [`ux-ui-guide.md`](ux-ui-guide.md), [`DESIGN.md`](../DESIGN.md), `.cursor/rules/ux-ui.mdc`.

## Принцип

Один код, две раскладки. Экраны стека общие; точки входа разные.

| Слой | Desktop | Mobile |
|------|---------|--------|
| Навигация | Рейка ~216px (иконка + подпись) в скруглённом окне | 4 иконки: Меню / Карта / Сообщения / Профиль + FAB по центру |
| Аккаунт | Шапка: аватар + имя | Вкладка Профиль |
| События | Стек в левой панели | Иконка на карте → stack |
| Каталог / лента / экспедиции / модерация | Широкая левая панель + справа карта над плеером | Меню-хаб → стек (каталог, лента, экспедиции) |
| Карта | По умолчанию на всю ширину. Кнопки рейки открывают панель | Вкладка Карта + FAB |
| Карточка / запись / профиль | Широкая левая панель + справа карта над плеером (зазор 8px) | Стек на весь экран |
| Низ окна | Копирайт и ссылки на политику / условия / правила публикации | Юридические документы в настройках |

Не показывать телефон 390×844 на проде.

## Mobile

```
[ search / filters on map ]
        MAP  (keep-alive rounded card)
   (player, then FAB gap)
[  Меню  |  Карта  |  +  |  Сообщения  |  Профиль  ]
```

Одна нижняя навигация (плавающая, скруглённая, safe-area). Карта не размонтируется при смене вкладки. Мини-плеер общий: над FAB и табами. Стек карточки закрывает табы. «На карте» / прогулка переключают вкладку Карта, без второго инстанса карты.

FAB всегда в вырезе по центру (запись / добавить звук). Меню — общий поиск и крупные разделы.

## Desktop

```
[ padded gray canvas ]
  [ rounded 32px app ]
    [rail 216: логотип ПОЛЁВКА, вкладки с текстом]
              [ header: search | bell | Войти / профиль ]
              [ MAP card (full)  ]   ← по умолчанию
              [ wide panel ][12][ MAP ]
                            [12]
                            [ player strip — не поверх карты ]
              [ © Полёвка · политика · условия · правила ]
```

Панель по умолчанию закрыта. Рейка: каталог / лента / экспедиции / сообщения (после входа) / модерация (staff). Повторный клик закрывает. Если человек не вошёл — кнопка «Войти» в шапке, без промежуточного кабинета гостя. Каталог, лента, помощь, сообщения, модерация, карточка звука, профиль, запись и черновик — широкая левая панель, справа карта, **под ней** плеер. Колокол открывает список рядом и закрывается повторным нажатием. Вход/регистрация — на весь экран.
