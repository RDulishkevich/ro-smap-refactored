# Архитектура интерфейса: ПК и мобильная версия

Канон: **React** в `apps/web`. Breakpoint: **desktop ≥ 768px**, **mobile < 768px** (`useIsDesktop`).

Связано: [`ux-ui-guide.md`](ux-ui-guide.md), [`DESIGN.md`](../DESIGN.md), `.cursor/rules/ux-ui.mdc`.

## Принцип

Один код, две раскладки. Экраны стека общие; точки входа разные.

| Слой | Desktop | Mobile |
|------|---------|--------|
| Навигация | Рейка 72px в скруглённом окне | 3 вкладки: Лента / Карта / Профиль |
| Аккаунт | Шапка: аватар + имя | Вкладка Профиль |
| События | Стек в левой панели | Иконка на карте → stack |
| Каталог / лента / экспедиции | Левая панель 360px | Подвкладки ленты |
| Карта | По умолчанию на всю ширину. Кнопки рейки открывают/закрывают панель 360px слева (зазор 20px) | Вкладка Карта + FAB |
| Карточка / запись / профиль | Широкая левая панель + справа карта над плеером (зазор 20px, пружина) | Стек на весь экран |

Не показывать телефон 390×844 на проде.

## Mobile

```
[ search / events on map ]
        MAP
   (FAB + record / add)
[  Лента  |  Карта  |  Профиль  ]
```

FAB только на карте (вырез 36px). Сообщения и колокол — в шапке ленты и в профиле.

## Desktop

```
[ padded gray canvas ]
  [ rounded 32px app ]
    [rail 72] [ header: title | search | bell | user ]
              [ MAP card (full)  ]   ← по умолчанию
              [ 360px panel ][20][ MAP ]  ← повторный клик закрывает
```

Панель по умолчанию закрыта. Рейка: каталог / лента / экспедиции / сообщения (после входа). Повторный клик закрывает. Вход — в шапке. Карточка звука, экспедиции, профиль, запись и черновик — широкая левая панель, справа карта над плеером. Вход/регистрация — на весь экран.
