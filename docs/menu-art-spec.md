# ТЗ: картинки для меню и баннеров

Публичное имя — **Полёвка**. Земляная палитра + mist `#92B3B1`. Без RO·SMap, без «Карта Звуков».

Картинки кладите в `apps/web/public/`. Сборка отдаёт их с корня сайта (`/menu/…`, `/banners/…`).

## 1. Плитки мобильного меню

Хабы в сетке 2 колонки: Лента, Каталог, Экспедиции, Ивенты, Настройки, Админ-панель, Помощь, Audio Guesser.

| Параметр | Значение |
|---|---|
| Кадр | **16∶10** (горизонтальный) |
| Файл @3x | **720 × 450 px** |
| Можно меньше | 480 × 300 (@2x) — минимум |
| Формат | WebP, sRGB. PNG только если нужна прозрачность |
| Вес | до **80 КБ** на плитку |
| Имена | `apps/web/public/menu/{slug}.webp` |
| slug | `feed` `catalog` `expeditions` `events` `settings` `staff` `help` `guessr` |

Безопасная зона: **24 px** от краёв — туда лягут скругление 24 px и подпись. Важный сюжет держите в центре.

Свет: тёплый день или мягкая дымка. Не неон, не чёрный киношный грейд. Поверх картинки будет лёгкий градиент и название раздела.

## 2. Баннеры в левой рейке ПК

Слот над «Помощь»: ширина рейки **216 px**, внутренний кадр ≈ **176 × 116 px**. Смена каждые **30 секунд**.

| Параметр | Значение |
|---|---|
| Кадр | **3∶2** |
| Файл @2x | **528 × 352 px** |
| Формат | WebP, sRGB |
| Вес | до **120 КБ** |
| Имена | `apps/web/public/banners/{id}.webp` |
| id сейчас | `listen` `walk` `guess` |

Текст на баннере рисует интерфейс (заголовок + подпись). На картинке **не верстайте** слова. Тёмные края снизу помогают читаемости.

## 3. Общие правила

- Цвета: терракота `#B5613F`, лес `#2D3C39`, олива `#6F7C4E`, шалфей `#9DB170`, mist `#92B3B1`, крем `#F4E8D8`.
- Без логотипа Полёвки на кадре — марка уже в шапке.
- Без лиц крупным планом без согласия; лучше поле, вода, приборы, карта, следы.
- Экспорт: sRGB, без EXIF с GPS, без водяных знаков.
- Если файла нет, интерфейс показывает цветную заливку — можно отдавать партиями.
