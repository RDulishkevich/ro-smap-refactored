Принципы

Продукт = карта звуков. Слушать · находить · добавлять. Social / экспедиции / админка — вторичные поверхности, не забивают listen-loop.

Делаем

  • Кремовые окна, угольный CTA, персик только как live/ember
  • 2px ink rim на soft fills (грамматика Wispr × идентичность Полёвки)
  • Geologica UI + Klukva brand @400
  • Iconsax · класс .hidden для скрытия
  • Копируем существующий паттерн UI, не изобретаем второй

Не делаем

  • Lavender / forest teal / Garamond / Figtree
  • Glow / amber halo / colored focus ring
  • backdrop-filter на dock / player
  • Peach как заливка больших панелей
  • Произвольные радиусы вне токенов

Типографика

Две роли, не «всё Klukva» и не «всё bold». Geologica = UI (body, chrome, player, buttons, catalog h2). Klukva @400 only = brand moments (wordmark, desktop .type-title). Klukva не умеет 700 — synthetic bold ломает метрики (так каталог и выглядел криво). На mobile <768 titles → Geologica 700, accent → ink (не peach).

--surface-elevated · inputs / nested

--surface-live · только ember

.ds-frame · --frame-dashed · analyzers / waveform / file-xfer-drop

Жёсткие правила

UX канон

  • Confirm / prompt → CustomUI
  • ⋯ / ПКМ / long-press → openActionsMenu → CtxPopup
  • Короткий фидбек → showToast
  • Auth-gated write: toast → openAuthModal → return
  • Desktop ≥768 · mobile <768

Технические запреты

  • Нет blur на #player-card / #sidebar
  • .hidden { display:none !important }
  • Icon-only controls → aria-label
  • Не красить схему Яндекс API палитрой
  • Selection / focus = ink rim, не glow
