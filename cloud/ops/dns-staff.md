# Staff-панель Полёвки

## Как войти

1. На сайте включите **2FA** (кабинет → безопасность) под staff-аккаунтом.
2. Откройте **https://www.polevka.art/staff/**
3. Введите **логин** и **код из аутентификатора** (пароль аккаунта не нужен).

Роли: `moderator` → `admin` → `owner` (владелец). Bootstrap-логин `admin` = owner.

Обычные пользователи **не** получают staff JWT. На основном сайте staff-роль **не** даёт модерацию/админ-действия — только после входа на `/staff` (`aud: staff`).

## Модули

| Раздел | Для кого | Что делает |
|--------|----------|------------|
| Обзор | все staff | очередь задач, быстрые переходы |
| Очередь | все | модерация с плеером |
| Жалобы | все | проблемные записи + прослушивание |
| Сообщения | все | обращения в поддержку (от лица `support`) |
| Люди | admin+ | настройки + полная хроника аккаунта |
| Аналитика | все | воронка / аудитория / типы |
| Консоль | owner | security events, email conflicts |
